# Changelog — Dynamic Overlay Joining

## Summary
Implemented dynamic query-time overlay joining. The module parses and indexes G-LRAG v2 validity timelines and authority indexes to compute document currency and resolve legal authority precedence on-the-fly without mutating base graph nodes.

## Motivation
Legal document validity and authority precedence change over time. Storing static currency properties on nodes locks the database to a single date state. Dynamic overlays allow the retrieval engine to evaluate currency relative to a user-supplied target date (`as_of_date`).

## Files Changed
* **Created:**
  - `src/knowledge_graph/overlay.py` (Validity timeline folder and authority precedence resolver)
  - `src/knowledge_graph/overlay_schema.py` (Overlay dataclass schemas)

## Major Implementation Details
* **Timeline Folding:** `compute_currency_status` chronologically sorts and folds validity events up to a query `as_of_date` (skipping unverified events).
* **Legal Precedence Conflict Resolution:** Resolves ranking conflicts by finding candidate ranks for document types, sorting them by rank (lower wins) and resolving tie-breakers by parsing the trailing numeric version values dynamically.
* **Overlay Isolation:** Evaluated overlays are stored separately in `DocumentOverlay` records, ensuring graph nodes remain read-only.
