\section{System Overview: L\_RAG}
\label{sec:system-overview}

This section details the end-to-end architecture of \textbf{L\_RAG}, a Knowledge-Graph-augmented hybrid RAG system engineered for legal information retrieval and question answering over Vietnamese legal corpora.

\subsection{Architecture}
\label{sec:architecture}

L\_RAG connects corpus indexing, hybrid retrieval, graph-based context
selection, candidate reranking, and cited generation. \hyperref[fig:architecture]{Figure~\ref{fig:architecture}}
illustrates the end-to-end query pipeline across five core operational phases:
(1) query scope and temporal constraint resolution,
(2) hybrid dense-sparse retrieval (E5 + BM25),
(3) knowledge-graph overlay filtering and context expansion,
(4) rank fusion and candidate reranking, and
(5) citation-grounded LLM prompting and answer generation.
This modular overview shows the available components; each ablation activates
the subset specified in Section~\ref{sec:configurations}. In particular, the
retrieval/graph family evaluates structural expansion without reranking or
query-time validity overlays.

\subsection{Retrieval Components}
\label{sec:retrieval-components}

The retrieval module combines three complementary retrieval approaches:

\subsubsection{Dense Vector Search}
Dense retrieval is powered by \texttt{intfloat/multilingual-e5-large}, a 560M parameter transformer embedding model. To solve the structural blindness of standalone chunks, each text chunk is preprocessed into a \textbf{Metadata-Enriched Representation}:
\begin{equation}
    \begin{aligned}
        \text{Text}_{\text{embedded}} ={}& \text{Doc\_Title} \parallel \text{Provision\_Header} \\
        &{}\parallel \text{Chunk\_Content}
    \end{aligned}
\end{equation}
Chunks are stored in an optimized FAISS vector database using \texttt{IndexFlatIP} with L2-normalized embeddings for fast cosine similarity search.

\subsubsection{Sparse Keyword Search (BM25)}
Sparse retrieval uses \texttt{rank\_bm25} with Vietnamese word segmentation
from \texttt{underthesea} and parameters $k_1=1.5$, $b=0.75$.
The retrieval/graph experiment partitions the corpus into 10 independently
built BM25 shards to fit the available memory. Candidates from each shard
are combined by BM25 score before dense--sparse RRF fusion. IDF and average
document length are estimated within each shard; the results therefore
characterize this practical sharded implementation. Shared corpus statistics
and alternative shard-merging policies offer useful directions for refinement.

\subsubsection{Knowledge Graph Overlay (G-LRAG Module)}
The Knowledge Graph module acts as a query coordinator that generates dynamic document filter whitelists (\texttt{id\_str\_filter}) and performs horizontal reading-order expansions. Key features include:

\begin{itemize}
    \item \textbf{Dynamic Overlay Folding:} Validity timelines are joined at query time relative to an \texttt{as\_of\_date} parameter to support filtering using the available validity metadata.
    \item \textbf{Precedence Sorting:} Candidates can be ordered using encoded legal-authority ranks:
    \begin{equation}
        \begin{aligned}
            \text{Hiến pháp} &\succ \text{Bộ luật / Luật} \\
            &\succ \text{Nghị định} \succ \text{Thông tư}
        \end{aligned}
    \end{equation}
    \item \textbf{Reading-Order Traversal:} \texttt{CHUNK\_NEXT} connects chunks within a provision, while \texttt{PROVISION\_NEXT} connects successive provisions. In the implemented hop convention, hop 1 covers the seed provision; additional hops reach subsequent provisions.
\end{itemize}

\subsubsection{Fusion Layer}
In the Hybrid retrieval/graph conditions, hit lists from dense search
($R_{\text{dense}}$) and sparse search ($R_{\text{BM25}}$) are merged using
Reciprocal Rank Fusion (RRF) with constant $k=60$. DenseOnly retains the dense
ranking without a fusion stage.

\subsection{Reranking Components}
\label{sec:reranking-components}

The reranker experiment selects $K=30$ candidate chunks per query and scores
the full $(query, chunk\_text)$ pair to refine the final ranking.

L\_RAG supports four alternative reranking backends. Evaluation conditions
load and run one backend at a time, rather than cascading all four per query:
\begin{enumerate}
    \item \textbf{\texttt{mMiniLMv2}:} \href{https://huggingface.co/cross-encoder/mmarco-mMiniLMv2-L12-H384-v1}{\texttt{cross-encoder/mmarco-mMiniLMv2-L12-H384-v1}} (Lightweight baseline, 117M params).
    \item \textbf{\texttt{BGE-Reranker-v2-m3}:} \href{https://huggingface.co/BAAI/bge-reranker-v2-m3}{\texttt{BAAI/bge-reranker-v2-m3}} (Multilingual 567M params with sigmoid activation).
    \item \textbf{\texttt{Jina-Reranker-v2}:} \href{https://huggingface.co/jinaai/jina-reranker-v2-base-multilingual}{\texttt{jinaai/jina-reranker-v2-base-multilingual}} (278M params, featuring dynamic position embedding patches).
    \item \textbf{\texttt{Qwen3-Reranker}:} \href{https://huggingface.co/Qwen/Qwen3-Reranker-0.6B}{\texttt{Qwen/Qwen3-Reranker-0.6B}} (CausalLM-based 0.6B parameter model evaluated in FP16 precision).
\end{enumerate}

To prevent GPU Out-Of-Memory (OOM) failures during multi-model evaluation, the loader executes a strict \textbf{Sequential Load-Run-Unload Cycle}:
\begin{equation}
    \begin{aligned}
        \text{Load}(M_i) &\longrightarrow \text{Execute}(M_i) \\
        &\longrightarrow \text{Delete}(M_i) \longrightarrow \texttt{empty\_cache}()
    \end{aligned}
\end{equation}

\subsection{Generation Component}
\label{sec:generation-component}

The non-generator ablations supply up to $N=10$ selected chunks to
\texttt{gpt-4o-mini} at temperature $T=0.0$. Context selection and output
settings follow each experiment's protocol. In the retrieval/graph family,
the client sets no explicit output-token cap and uses a shared Vietnamese
prompt with three evidence-oriented instructions:
\begin{enumerate}
    \item \textbf{Evidence grounding:} Use only the supplied context and cite legal sources when present.
    \item \textbf{Explicit abstention:} When evidence is insufficient, respond \textit{``Không có đủ thông tin trong ngữ cảnh được cung cấp.''}
    \item \textbf{Direct, scoped answers:} Answer naturally in Vietnamese, state any partial coverage, and omit internal reasoning. Benchmark answer types are evaluation labels, not prompt inputs in this family.
\end{enumerate}
Source citations support inspection; semantic citation verification is outside
the completed evaluation.
