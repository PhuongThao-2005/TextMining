\section{Experimental Setup}
\label{sec:experimental-setup}

We evaluate L\_RAG with controlled, paired ablations over the same Vietnamese
legal QA benchmark. The benchmark contains 500 questions: 400 answerable and
100 unanswerable. Runs within an ablation family use the same benchmark,
question identifiers, generator settings, and corpus/index version; only the
component named by the family is changed. This design is important because the
four completed families use different candidate budgets, as summarized in
Table~\ref{tab:configurations}.

\subsection{Research Questions}
\label{sec:research-questions}

We organize the experiments around five questions:
\begin{enumerate}
    \item Does adding document and provision metadata to the embedding text
    improve exact evidence retrieval or document-level coverage?
    \item Does hybrid dense--sparse retrieval improve coverage or ranking over
    dense retrieval alone?
    \item Does the current G-LRAG graph overlay improve evidence coverage and
    downstream behavior for the tested legal QA benchmark?
    \item Which reranker best trades ranking quality against inference cost
    when the candidate pool is held fixed?
    \item Which generator reasoning strategy should be used? The completed
    generator-reasoning comparison contrasts base prompting with explicit
    chain-of-thought (CoT) prompting under a fixed retrieved context.
\end{enumerate}

\subsection{Metrics}
\label{sec:metrics}

For answerable questions, retrieval is evaluated against the annotated gold
chunk IDs using Recall@$k$, Hit@$k$, MRR@$k$, nDCG@$k$, and Precision@$k$.
For graph runs we additionally report document-identity precision, because a
graph variant can return fewer chunks and therefore make a fixed-denominator
precision score misleading. The reranker analysis reports candidate
Recall@30 and candidate Hit@30 to distinguish the evidence ceiling from the
ability of a reranker to promote evidence already present in the candidate
pool.

For generated answers, we report exact match, token-level F1, and ROUGE-L on
answerable questions. We also report the template-based answerability
decision matrix (including non-refusal on answerable questions) and call its
aggregate ``decision accuracy'' rather than treating it as a legal-safety
metric. These automatic overlap and abstention measures are diagnostics rather than legal judgments:
the available artifacts contain no human labels for legal correctness,
completeness, claim faithfulness, or citation-to-chunk alignment. Those
metrics are consequently not inferred from lexical overlap.

Efficiency is reported as mean and median per-query latency, with p95 values
where the source run recorded them. The reranker runs used cached BM25
candidates and therefore report zero sparse-stage time; those values are not
treated as full-online hybrid latency.

\subsection{Evaluation Protocol}
\label{sec:protocol}

All completed runs use \texttt{intfloat/multilingual-e5-large} for dense
retrieval, temperature 0.0, and a maximum of 1,024 output tokens. The
non-generator ablations use \texttt{gpt-4o-mini}; the reasoning family varies
the generator model and prompt mode as listed in Table~\ref{tab:configurations}.
The embedding-text ablation uses raw FAISS
top-10 retrieval with no sparse, graph, fusion, or reranking module. The
dense/hybrid/graph ablation retrieves 50 seeds and supplies at most 10 final
chunks; graph variants expand five seeds by one hop with a maximum graph
context of 10. The reranker ablation reconstructs a shared RRF candidate pool
of 30 chunks (\texttt{C30}) and compares the top 10 final chunks
(\texttt{T10}). Its fusion constant is \texttt{rrf\_k=60}.

Comparisons are paired by \texttt{qa\_id}. Overall retrieval deltas use the
400 answerable questions. We report percentile bootstrap 95\% confidence
intervals for the mean per-question delta, using 10,000 resamples for the
main comparisons and 2,000 resamples for the smaller reranker slices. A
confidence interval containing zero is described as inconclusive rather than
as evidence of an effect. The reranker candidate reconstruction agrees with
the recorded RRF-only top-10 prefix for all 500 questions.

The generator-reasoning family holds the retrieval stack and intended retrieved
top-10 context fixed for each question, and changes the prompt mode for the
generator. The primary paired comparison uses the complete GPT-4o-mini Base and
CoT runs (500/500 questions, with 400 answerable pairs); their saved contexts
match exactly. The DeepSeek-V3.1-Thinking, GLM-5, and Qwen3-8B pairs are also
complete but remain descriptive cross-model checks. Four of the 500 shared DeepSeek cases have
different exact top-10 chunk-ID sequences between Base and CoT. The Qwen Base
and CoT manifests use different code snapshots, timeouts, and retry limits, so
their latency and failure comparisons are descriptive. These conditions are not
used for the primary paired claim. The post-hoc analysis and frozen result ledger are available at
\url{ablation_study/e2e_LLM_reasoning/results/report.md} and
\url{ablation_work/e2e_LLM_Reasoning/analyze_posthoc.py}.

\subsection{Evaluation Workflow and Derived Metrics}
\label{sec:evaluation-metrics}

Each condition is a saved 500-case run over the same question IDs, benchmark
labels, retrieved top-10 context, generation settings, and reference answers.
The post-hoc analysis reads these records and does not call a model or rerun
retrieval. A row is valid when it is not marked failed, errored, or skipped,
has no saved error, and contains a prediction. Lexical metrics use successful
answerable rows; a paired Base/CoT statistic uses only IDs that satisfy these
conditions in both runs and contain all three lexical metrics.

The original evaluator normalizes text with Unicode NFC, lowercasing,
punctuation-to-space replacement, and whitespace collapse. The derived metrics
are separated below so that answer-quality outcomes are not conflated with
retrieval, citation-structure, or operational diagnostics.

\paragraph{Primary metrics.}
The primary generated-answer metrics are computed on successful answerable
rows. For question $i$, let $y_i$ be the normalized prediction and $r_i$ the
normalized reference. Exact Match (EM) is
\[
\mathrm{EM}_i =
\begin{cases}
1, & y_i=r_i,\\
0, & y_i\ne r_i,
\end{cases}
\qquad
\mathrm{EM}=\frac{1}{N}\sum_{i=1}^{N}\mathrm{EM}_i.
\]
For boolean questions, the evaluator compares the first non-empty line. Let
$O_i$ be the multiset token overlap, $L_i^y$ and $L_i^r$ be the prediction and
reference token counts, and $C_i$ be the token-level longest common
subsequence (LCS) length. Token F1 is
\[
P_i=\frac{O_i}{L_i^y},\qquad
R_i=\frac{O_i}{L_i^r}.
\]
\[
F_{1,i}=\frac{2P_iR_i}{P_i+R_i}.
\]
ROUGE-L uses the same F-score form, replacing token overlap with the LCS:
\[
P_i^{L}=\frac{C_i}{L_i^y},\qquad
R_i^{L}=\frac{C_i}{L_i^r}.
\]
\[
\mathrm{ROUGE\mbox{-}L}_i=
\frac{2P_i^{L}R_i^{L}}{P_i^{L}+R_i^{L}}.
\]

For a paired Base/CoT comparison, only question IDs with valid outputs and
all three lexical metrics in both runs are retained. For any metric $m$, the
per-question paired delta and its mean are
\[
\Delta_i(m)=m_{\mathrm{CoT},i}-m_{\mathrm{Base},i}.
\]
\[
\overline{\Delta}(m)=\frac{1}{N_p}
\sum_{i=1}^{N_p}\Delta_i(m).
\]
Positive, zero, and negative deltas are counted as CoT wins, ties, and losses,
respectively. Deltas are reported in percentage points for percentage metrics.
Uncertainty is a percentile paired-bootstrap 95\% confidence interval from
10,000 resamples (seed 42); EM additionally uses an exact McNemar test on
discordant binary outcomes.

\paragraph{Additional diagnostics.}
These measures describe evidence availability, answer/refuse behavior,
citation structure, reliability, and efficiency. They are not direct tests of
legal correctness, citation entailment, or hidden reasoning.

\textbf{Context Recall@$k$.} Let $G_i$ be the gold chunk-ID set and $R_{i,k}$
the retrieved top-$k$ set:
\[
\mathrm{ContextRecall@}k_i=
\frac{|G_i\cap R_{i,k}|}{|G_i|}.
\]
Answerable cases are stratified as fully retrieved, partially retrieved, or
absent according to whether this value is one, between zero and one, or zero.

\textbf{Decision accuracy.} The persisted
\texttt{unanswerable\_accuracy} detector is mapped to answer/refuse
decisions. An answerable refusal is incorrect, while a refusal on an
unanswerable question is correct. The two reported denominators are
\[
\begin{aligned}
\mathrm{DecisionAccuracy}_{\mathrm{scheduled}}
  &=\frac{C_{\mathrm{scheduled}}}{500},\\
\mathrm{DecisionAccuracy}_{\mathrm{valid}}
  &=\frac{C_{\mathrm{valid}}}{N_{\mathrm{valid}}}.
\end{aligned}
\]
Here $C_{\mathrm{scheduled}}$ is the number of correct decisions among all
500 scheduled rows, $C_{\mathrm{valid}}$ is the number among valid rows, and
$N_{\mathrm{valid}}$ is the number of valid rows.

\textbf{Citation and structural diagnostics.} Citation presence is the
fraction of successful answerable answers containing at least one citation
marker:
\[
\mathrm{CitationPresence}=\frac{A_{\mathrm{marker}}}{A_{\mathrm{successful}}}.
\]
Here $A_{\mathrm{marker}}$ is the number of successful answerable answers with
at least one marker and $A_{\mathrm{successful}}$ is the number of successful
answerable answers.
If $F_i^{\mathrm{marked}}$ is the number of scored factual sentences with a
marker and $F_i^{\mathrm{scored}}$ is the total number of scored factual
sentences, structural coverage is
\[
\mathrm{StructuralCoverage}=
\frac{1}{N}\sum_{i=1}^{N}
\frac{F_i^{\mathrm{marked}}}{F_i^{\mathrm{scored}}}.
\]
Invalid-marker rate is the fraction of all markers that are invalid:
\[
\mathrm{InvalidMarkerRate}=
\frac{M_{\mathrm{invalid}}}{M_{\mathrm{all}}}.
\]

\textbf{Completion and latency.} Completion rate is
\[
\mathrm{CompletionRate}=\frac{S}{Q}.
\]
Here $S$ is the number of successful rows and $Q$ is the number of scheduled
rows.
For each saved latency summary, conversion from milliseconds to seconds is
\[
\ell_{\mathrm{seconds}}=\frac{\ell_{\mathrm{milliseconds}}}{1000}.
\]
The report uses the saved mean, median (p50), and p95 values. Reranker runs
used cached BM25 candidates, so their timings are not full-online hybrid
latency.
